# HTML standards for tags
1. Use `<header>` for:
   - Site title
   - Logo
   - Navigation
2. Use `<section>` for:
   - A stand-alone section of content
3. Use `<footer>` for:
   - Copyright information.
   - Terms and Conditions.
4. Use `<main>` for:
   - The main content of the document.
   - Unique content that is not repeated across pages.
   - Should only appear once per page.
